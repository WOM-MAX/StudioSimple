# Norma de Análisis Autónomo y Generación de /goal

## Directiva de Operación
Cada vez que el usuario pregunte o solicite analizar cualquier componente, archivo, flujo, datos o estado del sistema:

1. **Análisis Objetivo:** El agente debe realizar y exponer el análisis técnico y disciplinar con datos rigurosos y verificados.
2. **Plan de Acción Estructurado:** Generar de forma inmediata un plan detallado de ejecución que aborde los hallazgos, desalineaciones u optimizaciones encontradas.
3. **Prompt Autosuficiente con `/goal`:** Formular un bloque de prompt listo para ser ejecutado con el comando slash `/goal`, redactado con alcance end-to-end, contexto explícito, archivos involucrados y criterios de aceptación, de modo que el agente ejecute toda la tarea con autonomía total sin requerir intervenciones del usuario.
