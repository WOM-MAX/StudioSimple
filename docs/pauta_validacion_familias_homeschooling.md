# Pauta Formal de Observación y Validación Empírica en Terreno
## EstudioSimple · Validación de Sesiones de Aprendizaje en el Hogar (Homeschooling)

- Versión: 1.0 (Oficial)
- Fecha de Publicación: 2 de octubre de 2026
- Marco Rector: Manual Maestro de EstudioSimple (Versión 2.0, Apartados 14, 15, 27 y 28)
- Población Objetivo: Familias con estudiantes de 3° a 8° básico preparando Exámenes Libres (MINEDUC)

---

## 1. Propósito y Objetivos de la Validación

El presente instrumento tiene como propósito estandarizar la recolección de evidencia empírica en sesiones reales de aprendizaje conducidas por un adulto responsable (madre, padre o tutor) y un estudiante, con el fin de evaluar:

1. **Fidelidad y Viabilidad del Rol del Adulto:** Comprobar si un adulto sin formación pedagógica puede guiar la sesión con seguridad utilizando exclusivamente los recuadros DILE, PREGÚNTALE y apoyos socráticos.
2. **Comprensión y Aprendizaje Significativo del Estudiante:** Verificar la asimilación conceptual sin recurrir a la memorización mecánica, evaluando razonamiento y argumentación.
3. **Articulación Pantalla-Cuaderno Físico:** Constatar la transferencia efectiva del contenido audiovisual al registro manuscrito y gráfico en el cuaderno del estudiante.
4. **Presupuesto Temporal y Fatiga Cognitiva:** Medir los tiempos reales de cada etapa frente a los estándares de diseño (sesión total de 30 a 40 minutos) y registrar signos de distracción o sobrecarga.
5. **Usabilidad y Robustez Tecnológica:** Evaluar el funcionamiento de la sincronización dual, el reproductor de video universal y la navegación en diversos dispositivos (computador, tablet, smartphone).

## 4. Pauta de Observación del Rol y Mediación del Adulto

Escala de Evaluación:
1 = No observado / Conflicto severo
2 = En desarrollo / Requiere asistencia
3 = Satisfactorio / Conforme
4 = Sobresaliente / Fluidez total

| Criterio de Mediación Parental | Puntaje (1-4) | Evidencia Observable y Comentarios |
| :--- | :---: | :--- |
| **1. Fidelidad al Guion DILE:** El adulto lee textualmente las frases indicadas sin improvisar explicaciones teóricas complejas. | | |
| **2. Uso de Pistas Socráticas:** Ante un error o duda del estudiante, el adulto utiliza las pistas graduadas en lugar de entregar la respuesta directa. | | |
| **3. Respeto al Recuadro SOLO PARA TI:** El adulto mantiene la confidencialidad de las notas pedagógicas y no las lee en voz alta. | | |
| **4. Clima Emocional y Tono de Voz:** Mantiene un tono paciente, cercano y motivador; valida el esfuerzo ante respuestas erróneas. | | |
| **5. Manejo del Tiempo de Espera:** Da al estudiante al menos 10 a 15 segundos para pensar antes de intervenir o volver a preguntar. | | |
| **6. Manipulación de la Plataforma:** Maneja el avance de etapas y el reproductor de video con naturalidad y sin titubeos. | | |

## 5. Pauta de Observación del Desempeño y Experiencia del Estudiante

| Dimensión de Aprendizaje del Estudiante | Puntaje (1-4) | Evidencia Observable y Comentarios |
| :--- | :---: | :--- |
| **1. Atención Sostenida en Videos:** Mantiene la mirada y foco en las cápsulas de video (gancho y explicativa) durante toda su duración. | | |
| **2. Expresión Verbal de Ideas:** Formula explicaciones con sus propias palabras, evitando repetir de memoria las frases del video. | | |
| **3. Uso Efectivo del Cuaderno Físico:** Realiza los esquemas, notas y ejercicios a mano de forma legible y ordenada. | | |
| **4. Tolerancia al Error:** Recibe las pistas socráticas con apertura y ajusta su respuesta sin frustración ni bloqueo emocional. | | |
| **5. Autonomía en el Miniquiz:** Responde las alternativas de evaluación individualmente, justificando su elección antes de presionar. | | |
| **6. Metacognición y Síntesis:** En el Paso 8, logra verbalizar con claridad qué aprendió y qué estrategia le resultó más útil. | | |

## 6. Evaluación de Usabilidad, Tecnología y Ergonomía

| Parámetro Técnico | Estado (Conforme / Incidencia) | Descripción de la Incidencia (si aplica) |
| :--- | :---: | :--- |
| **Sincronización Dual:** Latencia entre la acción del adulto y la reacción de la pantalla del alumno menor a 1 segundo. | | |
| **Reproducción de Video:** Carga instantánea, sin buffering, audio sincronizado y controles responsivos. | | |
| **Legibilidad y Contraste:** Textos con escala adecuada (mínimo 16 pt), sin saturación visual ni elementos distractores. | | |
| **Persistencia de Estado:** Si la página se recarga accidentalmente, la sesión retoma exactamente en el paso activo. | | |
