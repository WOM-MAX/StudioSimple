Mapa de flujo sincronizado
Clase 1 · OA1 · Números enteros · Pantalla adulta y pantalla estudiante
OBJETIVO DEL DOCUMENTO: Convertir las decisiones aprobadas para la pantalla adulta en una secuencia funcional sincronizada. La pantalla del estudiante se describe como propuesta operativa y deberá revisarse visualmente antes de programar el prototipo.

Ruta funcional resumida
Portada → preparación privada → ruta del ramo → ascensor → referencia cero → video submarino → conversación guiada → video explicativo → idea clave → práctica conjunta → miniquiz → revisión/recuperación → cierre oral → finalización.
Reglas globales del prototipo
Solo los recuadros DILE se leen al estudiante. HAZ identifica una acción del adulto en la plataforma.
Toda pregunta oral ofrece, como mínimo, Respondió correctamente y Necesita apoyo. Las respuestas abiertas pueden incluir una ruta parcial.
El apoyo siempre reconoce el intento, normaliza que está aprendiendo y entrega una pista concreta; nunca califica al estudiante.
Los botones indican su alcance: ambas pantallas, solo estudiante o solo adulto. El ícono informativo explica el efecto antes de ejecutarlo.
La pantalla adulta mantiene visible el estado Estudiante conectado y el acceso permanente ¿Cómo funciona?.
Los términos internos de produccion no aparecen ante los usuarios. Gancho se reemplaza por Video o Desafío; Modelado por Explicación.
La respuesta esperada y el feedback responden exactamente a la pregunta formulada; no se evalúan criterios ocultos.
El miniquiz se aprueba con 2 de 3. La pregunta oral de cierre aparece solo después de alcanzar ese mínimo.
Finalizar clase significa aprobada. Terminar por hoy cierra la sesión sin aprobar y deja la clase pendiente de refuerzo.

PANTALLA DEL ESTUDIANTE

PANTALLA DEL ESTUDIANTE

F13. Recuperación obligatoria
Etapa lateral: Miniquiz  |  Flujo aprobado · banco equivalente pendiente
PANTALLA DEL ADULTO
PANTALLA DEL ESTUDIANTE
Proceso: Revisión guiada de cada error → apoyo especifico → una pregunta equivalente por cada respuesta incorrecta.
Recálculo: La pregunta equivalente reemplaza funcionalmente el ítem incorrecto para determinar si alcanza 2/3.
Si alcanza el mínimo: Se habilita la pregunta oral de cierre.
Si no alcanza: Opciones Reforzar ahora / Terminar por hoy.
Apoyo: Visual y explicación positiva para cada concepto no logrado.
Segunda comprobación: Solo preguntas equivalentes a los conceptos fallados, no repetición literal.
Si se termina: Mensaje de avance sin declarar la clase completada.
CONTROL Y SINCRONIZACION
Ejemplo: con 1/3, se recuperan dos conceptos; basta lograr uno para alcanzar 2/3.
Con 0/3, se recuperan tres conceptos y necesita lograr al menos dos.
Terminar por hoy registra Clase pendiente de refuerzo y no habilita Clase 2.
F14. Cierre oral · explica lo aprendido
Etapa lateral: Cierre  |  Aprobado
PANTALLA DEL ADULTO
PANTALLA DEL ESTUDIANTE
Condición de entrada: Solo aparece cuando el estudiante ya alcanzo 2/3, en el primer intento o después de recuperación.
DILE: Con tus palabras, ¿para qué sirven el cero y los signos positivo y negativo cuando queremos representar una situación real?
Respuesta lograda si: 1) expresa que el cero funciona como punto de referencia; 2) explica que los signos indican dónde se encuentra un valor respecto de ese punto. Puede usar sus propias palabras o un ejemplo correcto.
Selecciona: Explicó ambas ideas / Explicó solo una idea / Necesita apoyo.
Visual: Resumen sobrio con 0 como referencia y ejemplos positivo/negativo; no muestra la pauta antes de responder.
Tras resolver: Síntesis visual de la idea central.
CONTROL Y SINCRONIZACION
Si explica una sola idea, el adulto marca cuál y recibe solo la pregunta faltante.
La distinción posición/movimiento ya fue evaluada antes; no se agrega como criterio oculto en esta pregunta.
BIFURCACIONES
Ambas ideas: feedback que reconoce punto de referencia y signos.
Solo cero: preguntar para qué sirven positivo y negativo.
Solo signos: preguntar qué punto debe establecerse antes.
Necesita apoyo: volver al edificio, preguntar qué representaba 0 y cómo se diferenció el estacionamiento −3; luego pedir que lo explique nuevamente.
